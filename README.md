# Monefy QA Assessment - Sadgi Nayak

This repository contains the deliverables for the Monefy Mobile Application testing tasks.

## 📂 Project Structure
* **[Task 1: Exploratory Testing](./task-1-exploratory/)** - Findings, Charters, and Risk Analysis.
* **[Task 2: Mobile Automation](./task-2-mobile-automation/)** - Appium/Java framework for E2E flows.

## 🛠️ Quick Start (Automation)
1. Navigate to `task-2-mobile-automation/src/test/resources/config.properties`.
2. Input your Sauce Labs credentials.
3. Run `mvn clean test` from the automation folder.
